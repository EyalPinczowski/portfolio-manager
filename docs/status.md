## 2026-10-04 (Analyze a stock, backend)
- Built `GET /api/analyze/{symbol}?portfolio_id=&amount=&currency=&horizon=&risk=` and `POST /api/analyze/{symbol}/ask` (`backend/app/api/analyze.py`, code in `backend/app/analyze/`: `chartist.py`, `scout.py`, `fit.py`, `service.py`, `public_facts.py`, `schemas.py`). Any US/TASE/crypto ticker, owned or not; a `portfolio_id` of someone else is a 404 before anything is fetched. Scout and Chartist are deterministic and typed (signals other than technical/patterns are listed as not available, confidence 0). `portfolio_fit` is the headline: max size allowed, position/sector/country exposure before and after the amount (rule names when a cap breaks), size shrunk to fit (stop never tightened), entry/stop/take-profits from `compute_exit_levels`, held vs new, per-rule results. Amount, currency and horizon have no defaults (they come back in `needs_input`; a holding's own horizon is used when it has one). A stale or missing price gives no levels with the reason.
- No verdict: `candidate_info` has score, confidence, fit pass/fail and the launch-gate state only. Summary is a template; `PublicFacts` is the only object an AI prompt may be built from (not wired: no LLM is called). `/ask` answers from computed numbers with a template; notes are not stored (no infra) and nothing is sent to an AI provider.
- Cache: one `SignalCache` row `analyze:<SYMBOL>` (chart report, bars, quote), TTL `analyze_cache_ttl_minutes` (15); a fresh row means no provider call. Tests: `tests/test_analyze.py` (35), a row in `tests/test_api_scoping.py`; `openapi.json` regenerated. Changed one word in the exit-levels message ("hold" -> "keep") so no verdict word appears in responses.
- Needs the user's decision: the `volatility_cap` rule reuses the unapproved screener caps; what an open launch gate should show (no verdict route exists yet); whether notes get stored; per-user rate limit on cache misses (not added).
- Next: frontend `npm run gen:api` and `/analyze/[symbol]`; News/Bear/CIO roles and fundamentals Scout fields.
